# Abhilash Hariwal — Portfolio (Node.js)

## Run locally
```
npm install
npm start
```
Then open http://localhost:3000

## Deploy
Push this folder to a GitHub repo and deploy on Render, Vercel, or Railway (all detect the Express `start` script automatically).
